Experiment Setup

NCAs are evolved by an elitist strategy with candidates rolled out from random initial states. Runs are selected for dynamics that stay non-collapsed while remaining hard for probe models to predict.

NCA rule

circular_pad_1 -> Conv3x3 3 -> 4 -> Conv1x1 4 -> 16 -> ReLU -> Conv1x1 16 -> 3 x[t+1] = clamp(x[t] + 0.05 * f(x[t]), 0, 1)

Fitness

fitness = preq * 1[gzip_ratio > threshold] preq = sum_t max(loss[t] - loss_final, 0) gzip_ratio = gzip_bytes(quantized_rollout) / raw_bytes
